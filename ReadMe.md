RunTxt was created as a long-distance communication tool without the need for an internet connection. Instead of shouting as loud as possible, it is better to show text or Morse code on the phone screen.


### Running Text
An animation test that can run on the phone screen.
* **Aware Text Direction** Sometimes text can be written from left-to-right and right-to-left; the running text will adjust accordingly.
* **Presets** A collection of pre-configured settings, so you don't have to worry about creating text designs—just use what's already available.
* **Speed** Text speed settings with a maximum of 500 px/s and a minimum of 50 px/s.
* **Animation Text** Running animations like text moving from left to right or right to left for text starting from the right. Additionally, it provides a text blinking animation if blink mode is enabled.
* **Mirror Mode** This feature is useful if the text is viewed through a mirror reflection so it can be read properly.
* **Font Style** Settings for various font styles and text shapes.
    * **Variant Font** Currently, there are 57 fonts available locally and online using Google Fonts. For the fonts themselves, they can be viewed here: [fonts.json](app/src/main/res/raw/fonts.json)
    * **Script Support** Fonts support various writing systems and scripts, such as Latin, Arabic, Japanese, Chinese, Korean, Thai, Devanagari, Khmer, and Hebrew.
* **Background** adalah background layar yang dapat diatur dengan warna solid
* **Text Color** Text color terdapat 2 pilihan yaitu warna solid dan gradient.
    * **Solid Color** Text color dapat diatur dengan warna solid
    * **Gradient Color** Text color dapat diatur dengan warna gradient dan dapat di atur panjang grandient dan orientasi gradient seperti vertical dan horizontal
* **Outline** mengatur garis pinggir pada teks seperti
  * **Outline Color** mengatur warna outline color secara solid memiliki nilai transparat
  * **Outline Width** mengatur lebar garis outline minimal bernilai 1 maximal bernilai 10
* **Drop Shadow** mengatur bayangan pada teks seperti
  * **Color** mengatur warna banyangan secara solid memiliki nilai transparant
  * **Radius** mengatur bayangan radius tingkat blur pada bayangan teks
  * **Rotation** mengatur posisi rotasi bayangan
